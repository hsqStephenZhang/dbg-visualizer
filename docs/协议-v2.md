# GDB 递归文本协议 v2

当前实现：`crates/visualizer-runtime/src/protocol.rs` 与 `crates/visualizer-runtime/gdb.py`。仅支持 64 位小端 Linux 本地 GDB；不兼容 v1，无子节点分页协议。

## 注册与类型关联

非泛型 `derive(Visualize)`、`#[dbgvis::register]` 或 `dbgvis::register_type!(T)` 为每个具体根生成唯一标记、typed anchor、`Registration<T>` 工厂及 linkme 条目。Rust 内保存独立的 marker TypeId 和具体类型身份 TypeId，不经 wire 传输。前者检测 marker 误用，后者决定是否可合并 formatter。

应用调用一次无参数 `dbgvis::enable!()`，导出 `DBG_VIS_MODULE_V2` 及唯一的 `unsafe extern "C" fn dbgvis_dispatch_v2(request: usize) -> u64`。runtime 的 `#[linkme::distributed_slice] pub static VIS_TYPES: [fn() -> Root]` 收集当前链接产物中的工厂指针。enable 调用工厂、按类型名排序、检查重复并冻结 v2 表；后续格式化不扩展它。同名登记只有具体类型身份一致且 size/align 一致才合并能力；身份不同即使布局相同也拒绝。按类型名和 anchor 名排序后保留首条默认模式和每种能力的首个入口。marker 不可用于不同类型。

GDB 仍读取原来的 v2 模块头和 Entry，不解析 linkme 的 linker section、不从 Python 调用工厂。工厂只生成元数据，启动阶段没有业务 fmt 调用；linkme 没有动态注册构造器，但 enable 的遍历/分配保留。泛型 derive 不隐式生成所有单态化实例；无参数 derive 可用 `no_register` 禁用自动根登记。

`Registration<T>` 不变型地绑定 T 与 auto/Visualize/Debug/Display 函数，不能通过 builder 混搭另一 U 的函数。静态 anchor 的空 `*const T` 字段仅供 GDB 读取 DWARF，永不解引用。

借用根使用宏生成的生命周期擦除身份：对登记类型的自由生命周期替换为 `'static`，取该具体类型的 TypeId；格式化入口仍在生命周期泛化的 helper 中生成。普通 `Registration<T>::new` 要求 T: 'static；宏内部通过 unsafe `new_lifetime_erased<Identity, Marker>` 关联身份，其契约要求 Identity 与 T 只允许有生命周期差异。该身份只用于本次构建内合并，不是目标对象的运行时 TypeId。不能在回调中把实际借用延长为 `'static`；生命周期只针对 `'static` 有效的显式 fmt 实现不满足泛化注册。

GDB 发现过程只读符号/内存/调试信息，不执行目标函数。匹配检查所属主 objfile、完整类型名称、类型身份；GDB Rust enum 跨编译单元类型等同性不足时，另比较完整 DWARF 结构，包括名称、大小/对齐、字段偏移/类型、数组界限及枚举活动变体。结构体动态类型可能缺少尾部 padding，比较时按对齐恢复范围。存在多个候选或信息不完整时拒绝。

以上是调试器防误用措施，不是无条件的 Rust 类型身份/内存安全证明。当前不承诺同名不同 crate 版本及所有优化状态；不将一个同名同大小对象直接视为另一个 T。最终调用者仍承担对象真实类型、存活和共享访问有效性要求。

## 模块头

`Module` 为 `repr(C)`，128 字节，Python 格式 `<8s15Q`。Q 均为目标小端 64 位值：

| 偏移 | 字段 | 值/含义 |
| --- | --- | --- |
| 0 | magic | 8 字节 `DBGVIS02` |
| 8 | abi | 2 |
| 16 | size | 128 |
| 24 | pointer_width | 8 |
| 32 | endian | 1，小端 |
| 40 | entry_size | 96 |
| 48 | request_size | 80 |
| 56 | response_size | 40 |
| 64 | ready | 初始化完成为 1 |
| 72 | entries | 不可变注册表地址 |
| 80 | count | 0–4096，空表合法 |
| 88 | request | 唯一请求邮箱地址 |
| 96 | response | 响应邮箱地址 |
| 104 | output | 输出区地址 |
| 112 | capacity | 编译输出上限 |
| 120 | dispatcher | C ABI 函数地址 |

ready/entries/count 在 Rust 中为原子，enable 发布 ready。GDB 只在目标全停时读取；未初始化时不尝试调用 enable。

## 注册条目

`Entry` 96 字节，Python `<12Q`：

| 偏移 | 字段 |
| --- | --- |
| 0 / 8 | Rust type_name 文本地址 / UTF-8 长度 |
| 16 / 24 | anchor 符号文本地址 / 长度 |
| 32 / 40 | size_of T / align_of T |
| 48 | capabilities 位集：AUTO=1、VISUALIZE=2、DEBUG=4、DISPLAY=8 |
| 56 | 默认模式（单个能力值） |
| 64 / 72 / 80 / 88 | auto / visualize / debug / display 函数指针，可为 0 |

条目内函数是 **Rust ABI 的内部指针**，Python 不能直接调用。Python 只调用模块头的 C ABI dispatcher。文本按长度读取，不依赖 NUL。

## 请求与响应

`Request` 80 字节，`<10Q`：

| 偏移 | 字段 | 约束 |
| --- | --- | --- |
| 0 / 8 | abi / size | 2 / 80 |
| 16 | sequence | 每个请求新序号 |
| 24 | slot | 当前表中索引 |
| 32 | object | 实际存活 T 的地址，非空且对齐 |
| 40 | mode | 0 表示条目默认；1/2/4/8 表示已登记能力 |
| 48 | capacity | 1 到编译上限 |
| 56 | alternate | 0 或 1 |
| 64 | max_depth | 1–128 |
| 72 | max_nodes | 1–1000000 |

模式不是 fallback 列表：选择后只执行一次。AUTO 内部优先 Visualize > Debug > Display；递归中三者缺失应在代码生成阶段拒绝，不是 wire 动态查表失败。

dispatcher 只接受发布的邮箱地址；不能传入任意 Request 指针。进入时用非等待 CAS busy guard 防重入，随后检查参数再构造 `&T`。非空/对齐检查不能证明对象仍存活或符合不变量。

`Response` 40 字节，`<5Q`：sequence、status、written、outcome、nodes。返回值也为 status，GDB 必须核对两者一致以及 sequence、输出长度。所有正常错误响应 written=0，不泄漏上次输出；非法邮箱或忙状态在进入前直接拒绝，不承诺刷新响应邮箱，GDB 此时应停止后续主动调用。

| status | 名称 | 行为 |
| --- | --- | --- |
| 0 | OK | 完整 UTF-8 文本 |
| 1 | LIMITED | 合法 UTF-8 前缀及具体原因 |
| 2 | UNSUPPORTED | 模式未登记 |
| 3 | INVALID | 参数无效 |
| 4 | ABI_MISMATCH | 协议不兼容 |
| 5 | BUSY | 不等待、不得清除 busy 强行继续 |
| 6 | FORMAT_ERROR | fmt::Error，未当作预算停止 |
| 7 | PANIC | unwind 在 C ABI 内侧捕获 |
| 8 | NOT_READY | enable 尚未完成 |

outcome：0 完整、1 字节限制、2 深度限制、3 节点限制、4 当前路径循环、5 格式化错误。LIMITED 的前缀不保证括号闭合或可机器解析。GDB 在 Rust 输出之外追加诊断标记，不占用目标 capacity。

## 执行、缓存与安全

一次根请求只进入 dispatcher 一次，Rust 将所有嵌套值写入同一个有界区；没有 count/page/child-address 请求。根注册表可分配；正常框架递归路径用固定大小访问路径栈及输出区，不先创建完整字符串。

输出默认上限 65536，`DBGVIS_BUFFER_BYTES` 编译时可设 1–16777216；请求默认 4096、深度 32、节点 4096。超限不自动重试。直接 Debug/Display 和用户手写 Visualize 的计算、分配和循环不受框架节点预算约束。

GDB 默认为 native/manual。automatic 还要求本地异步调用超时支持；200ms 默认设置在 GDB 中向上取整为 1 秒。目标全停且允许函数调用时才执行，不主动释放锁或撤销应用副作用。

panic hook 可能执行任意用户代码。unwind panic 捕获后，若 payload 析构再次 panic，则丢弃第二个 payload（有意泄漏）以免穿过 C ABI。abort、退出、超时、信号或不能确认返回时，GDB 标记 poisoned，刷新/重置配置不解除；恢复要求真正重启目标进程。

元数据在继续执行、模块加载/清理、退出时失效；文本完全不跨请求缓存。core dump、无真实存储、类型歧义、没有执行权限时保留原生视图。调试器脚本及被执行 formatter 都需要用户信任。
